🚀 Vercel Deployment Fix Guide

Fix the deployment error for your RDMSystem frontend

❌ Current Status: Deployment Failed
🎯 What happened: Your latest commit with security improvements was pushed to GitHub successfully, but Vercel couldn't build the frontend because it was looking in the wrong directory.

📋 Quick Fix - Option 1 (Recommended)

Update your existing Vercel project settings. This takes 2 minutes.

1 Open Vercel Dashboard

Go to https://vercel.com/dashboard

Find your project: hatsun-rdms-app

Click on the project name to open it

2 Go to Project Settings

Click the Settings tab at the top

Settings tab location: Top navigation bar
3 Update Root Directory

Scroll down to Build & Development Settings

Find the Root Directory setting

Change from ./ to frontend

Root Directory: frontend

✅ Click Save

4 Add Environment Variable

In the same Settings page, scroll to Environment Variables

Click Add New

Enter the following:

  • Key: VITE_API_BASE_URL
  • Value: Your Render backend URL (see below)
  • Environments: Select all (Production, Preview, Development)
⚠️ Important: Your backend URL should look like:
https://your-backend-name.onrender.com
Do NOT add /api at the end - the frontend adds it automatically!
5 Redeploy

Go to the Deployments tab

Find the latest deployment (the failed one)

Click the three dots (⋯) next to it

Click Redeploy

✅ Wait for the build to complete (2-3 minutes)

✅ Done! Your frontend should now deploy successfully. You'll receive an email when deployment completes.

🔄 Alternative - Option 2

1 Delete Current Project

Critical settings:

  • Framework Preset: Vite (auto-detected)
  • Root Directory: frontend ← MOST IMPORTANT!
  • Build Command: Leave empty (auto-detected)
  • Output Directory: dist
4 Add Environment Variable

Click Add Environment Variable

Key: VITE_API_BASE_URL

Value: https://your-backend.onrender.com

5 Deploy

Click Deploy

Wait for build to complete

🔍 Finding Your Backend URL

You need your Render backend URL for the environment variable.

  1. Go to https://dashboard.render.com
  2. Find your backend service
  3. Copy the URL at the top (looks like: https://xxxxx.onrender.com)
  4. Use this URL in Vercel WITHOUT /api at the end
Example:
If your Render backend URL is:
https://hatsun-rdms-backend-xyz.onrender.com

Set in Vercel as:
VITE_API_BASE_URL=https://hatsun-rdms-backend-xyz.onrender.com

✅ Verification Checklist

  • Root Directory is set to frontend
  • Framework is detected as Vite
  • Environment variable VITE_API_BASE_URL is added
  • Backend URL does NOT have /api at the end
  • Redeployment has been triggered
  • Build logs show success (check Deployments tab)

🐛 Troubleshooting

Still failing after configuration?

Check the build logs:
  1. Go to Deployments tab in Vercel
  2. Click on the failed deployment
  3. Click "Building" to see logs
  4. Look for specific error messages

Common Issues:

  • "Cannot find package.json" → Root Directory is wrong, set to frontend
  • "API connection failed" → Check VITE_API_BASE_URL environment variable
  • "Build succeeded but page is blank" → Check browser console for errors, verify API URL
  • "CORS errors" → Your backend's CORS settings need to include your Vercel domain
